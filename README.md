# Mnb-0.github.io

`https://mnb-0.github.io/parallax/` is printed as a QR code on the Parallax poster. It must never move.

## Change where the QR code goes
1. Open `parallax/index.html`.
2. Set `var DEST = "https://your-app-url";` (leave it as `""` to show the holding page instead).
3. Commit and push to `main`. GitHub Pages updates within a few minutes.

## Do not
- Rename the GitHub account `Mnb-0` or this repository.
- Delete or move the `parallax/` folder.
- Make this repository private (Pages on a free account needs a public repo).
